In this chunk of the project I learned,

1) Docker containers' filesystem and network is independent of the host (e.g. my mac, rpi). We have to explicitly copy over files and bind ports if we want to use them.

2) The machines (or docker containers) I've designated as **workers** and **coordinators** are not the same as the spark **executors** and **driver**.
